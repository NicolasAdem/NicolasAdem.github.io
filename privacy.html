Privacy policy

Last updated: 27 November 2026.

Build Anything Overnight is a personal tool used only by its developer, Nicolas Adem.

What it accesses

Read-only access to the user's own Google Calendar events and calendar list, only after the user signs in with Google and grants it.

How the data is used and stored

Calendar data is used only to answer the user's own questions and remind him of his own events. It is stored only on the user's own computer. It is not sold, shared with third parties, used for advertising, or used to train AI models.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions; stored data is deleted from the user's computer on request.
